# 来源研究、代理访问与接入条件

## 1. 本轮证据

核验日期：2026-09-16。使用本机既有 HTTP 代理完成公开、无登录态的只读请求；代理地址和凭据不写入仓库。未关闭 TLS 校验，未尝试验证码、登录 Cookie、指纹伪装或代理轮换。

| 请求 | 实际结果 | 能得出的结论 |
| --- | --- | --- |
| [JavDB robots](https://javdb.com/robots.txt) | 目标 HTTP 200，`text/plain`，264 bytes | robots 可读；全站规则包含 `Crawl-delay: 20`，禁止 `/tags`、`/recent_videos`、`/search` 和 `/cdn-cgi/` |
| [JavDB 首页](https://javdb.com/) | 目标 HTTP 200，真实 HTML，69,234 bytes | 当前代理路径可访问公开页面；首页仅用于离线发现详情链接 |
| JavDB 两个 `/v/<id>` 详情页 | 均为目标 HTTP 200，82,960 / 55,569 bytes | `video-detail`、番号、标题、日期、片商、演员结构在两个样本上成立；已实现固定版本解析器 |
| [Jable robots](https://jable.tv/robots.txt) | 目标 HTTP 200，`text/plain`，630 bytes | robots 可读，并禁止登录、播放器、异步和验证码等路径 |
| [Jable 首页](https://jable.tv/) | 目标 HTTP 403，`Cf-Mitigated: challenge` | 按规则停止该来源；不尝试绕过挑战，不开发未经样本验证的解析器 |

JavDB robots SHA-256 为 `3DCF9AB49ECE600E5CCEA444CB0DF58D274758FC72FEC4204809A8EBE88A0CBB`；Jable robots 为 `754278BEC894D8277E7828B910B8CE76401362FBAB84586E4C3944DA801FA7E5`。两个详情样本的 hash、解析结果与代码版本见[实施记录](./IMPLEMENTATION_LOG.md)。原始 HTML、响应头和真实候选保存在被 Git 忽略的 `runtime/`；含临时 Cookie 的原始响应头不保留。

这些结果证明“本次测试可访问、字段结构可解析”，不等于来源条款允许长期自动采集，也不等于字段事实已获发布授权。JavDB 继续保持 `network_enabled=false`、`terms_status=unverified`、`rights_status=needs_review`。

## 2. 来源分工与当前状态

| 来源 | 当前状态 | 拟解决的问题 | 不作出的推断 |
| --- | --- | --- | --- |
| JavDB | 两个公开详情样本已验证；本地解析器可用；自动联网关闭 | 目录候选、作品身份与关系补全 | 不把排名、评分、磁力或抓取顺序当成本平台数据；不自动发布人物关系 |
| Jable | robots 可读，首页 403 挑战，停止 | 原计划用于已知作品身份的第二来源核对 | 不绕过挑战；页面上传/上架日期不等于发行日期；不采集播放或下载入口 |
| 官方 / 人工资料 | 待逐来源确认 | 填补无可靠证据的厂牌、公开艺名及授权图片 | 不因域名含“官方”就自动授予权威性 |
| fixture | 可用 | 开发阶段验证合同与流程 | 不计入真实数据量、真实来源或准确率 |

优先顺序是“可持续访问、使用范围明确且字段可解释的来源”，不是预先指定某站拥有覆盖所有字段的权威性。若来源无法准入，继续使用项目既有人工录入 / CSV 流程或获得许可的资料源，前端展示不依赖单一站点。

## 3. 连接器核验范围

`javdb-html@2026-09-16.1` 只接受无凭据的 `https://javdb.com/v/<id>` 页面和显式保存的本地 HTML。必填锚点为 `.video-detail`、番号和标题；日期必须为 ISO 日历日期。片商和演员可缺失，保留空值。候选保存页面 URL、页面标题、原始值、结构路径、核验时间、解析器版本、置信度和 `rights_status=needs_review`。

当前两个样本覆盖正常详情、单人/多人和完整五字段。尚需补齐：缺失日期、缺失片商、同番号多版本、非作品页、页面结构变化和历史样本。解析器已有挑战页、非法 URL、非法日期、可选字段缺失、重复来源对象和连接器版本错误测试；不足的真实样本覆盖不得用合成测试冒充。

robots 可达只是证据之一；还需核对条款与拟展示内容的使用范围。来源访问被拒绝时停止该来源，不将换区域或换代理作为绕过手段。区域用于已允许访问范围内的执行分工。

## 4. 请求预算与网络设计

通用起步建议保存在[来源登记文件](../../data/collection/source-registry.json)：并发 1、20 页/任务、100 条/任务、200 页/日/来源、单响应 2 MiB、总响应 20 MiB、单请求 20 秒、任务 10 分钟。JavDB 已观测到更严格的 20 秒 crawl delay，因此该来源按至少 20 秒执行。图片候选初期关闭。数字是工程上限，不代表来源许可；启用时取来源规则、条款与工程上限中最严格的值。

使用用户指定代理属于网络传输配置。生产设计通过部署 secret 注入代理地址，不允许任务 payload 携带代理、Cookie 或任意请求头。采集目标仍受允许主机、路径、DNS 地址范围和重定向校验控制；代理端远程 DNS 场景还需要代理出口执行等价的私网目标阻断。

首次结构探测与连接器修复走人工任务；稳定且完成准入后再启用增量。实际 403 / 登录页 / 验证码停止来源，429 遵循 Retry-After，网络超时退避，解析必填锚点缺失停止对应版本。目标网页响应、代理 CONNECT 与本地异常分开记账。
