# 来源研究、代理访问与接入条件

## 1. 本轮证据

核验日期：2026-09-16。用户原文 `javdb.com.jable.tv` 按两个域名 `javdb.com` 和 `jable.tv` 理解；随后用户明确要求使用对应代理访问 JavDB。

| 请求 | 方式 | 实际结果 | 能得出的结论 |
| --- | --- | --- | --- |
| [JavDB robots](https://javdb.com/robots.txt) | 直连 | 沙箱内 DNS 失败；允许联网的只读请求连接超时 | 未取得 robots 内容 |
| [Jable robots](https://jable.tv/robots.txt) | 直连 | 沙箱内 DNS 失败；允许联网的只读请求连接超时 | 未取得 robots 内容 |
| [JavDB 首页](https://javdb.com/) 与 robots | 用户要求的现有 HTTP 代理 | CONNECT 返回 200；TLS 握手被对端重置，curl 退出码 35，目标 HTTP 码 000 | 代理隧道可建立，目标正文仍不可访问 |

代理从本机已有服务配置读取，仅传给子进程环境，没有写入仓库、日志或浏览器。CONNECT 200 是代理隧道响应，不是 JavDB 页面返回 200。未关闭 TLS 校验，也未尝试验证码、登录 Cookie、指纹伪装或代理轮换。

当前未获得 HTML、robots、条款、站点地图、API 或字段选择器证据；**不能声称两站允许采集，不能声称某个 DOM 路径已验证**。以下来源职责与字段均为待验证的接入假设。演示中的名称、作品、hash 和观测不是两站数据。

## 2. 来源分工假设

| 来源 | 拟解决的问题 | 拟核验字段 | 不作出的推断 |
| --- | --- | --- | --- |
| JavDB | 目录候选、作品身份与关系补全 | 番号、标题、明确发行日期、厂牌、公开人物别名 | 不把排名、评分或抓取顺序当成本平台热度 |
| Jable | 对已知作品身份做第二来源核对 | 番号、标题、人物线索 | 页面上传/上架日期不等于发行日期；不采集播放或下载入口 |
| 官方 / 人工资料 | 填补无可靠证据的字段 | 厂牌原始资料、公开艺名及授权图片 | 不因域名含“官方”就自动授予权威性 |
| fixture | 开发阶段验证合同与流程 | 本地合成元数据 | 不计入真实数据量、真实来源或准确率 |

优先顺序是“可持续访问且字段可解释的来源”，不是预先指定某站拥有覆盖所有字段的权威性。若两站无法准入，继续使用项目既有人工录入 / CSV 流程或获得许可的资料源，前端展示不依赖单一站点。

## 3. 来源核验任务

每个域名单独记录负责人、核验时间、请求 URL、目标 HTTP 状态、robots 与条款证据位置、允许的区域与请求路径。访问成功后，先采集少量允许使用的脱敏页面样本，人工对照字段含义，才开始开发解析器。

验收样本至少覆盖：正常作品、缺失日期、多人、别名、同番号多版本、非作品页、空列表、分页边界、页面结构变化和访问受限响应。人数与数量仅是工程测试覆盖要求，不是对网站内容或接口的断言。

连接器登记内容：固定版本、允许主机/路径、选择器或结构字段、必填锚点、字符编码、分页结束条件、增量游标、HTTP 与总资源预算、错误分类、parse fixture 测试、变更记录。保留原始字段值与标准化值，来源结构变化时不将整页文本误当标题。

robots 可达只是证据之一；还需核对条款与拟展示内容的使用范围。来源访问被拒绝时停止该来源，不将换区域或换代理作为绕过手段。区域用于已允许访问范围内的执行分工。

## 4. 请求预算与网络设计

起步建议保存在[来源登记文件](../../data/collection/source-registry.json)：并发 1、至少间隔 10 秒、20 页/任务、100 条/任务、200 页/日/来源、单响应 2 MiB、总响应 20 MiB、单请求 20 秒、任务 10 分钟。图片候选初期关闭。数字是保守的工程上限，不代表来源许可；启用时取更严格的上限。

使用用户指定代理属于网络传输配置。生产设计通过部署 secret 注入代理地址，不允许任务 payload 携带代理、Cookie 或任意请求头。采集目标依然受允许主机、路径、DNS 地址范围和重定向校验控制；代理端远程 DNS 场景还需要代理出口执行等价的私网目标阻断，不能只校验本机 DNS 后让代理重新解析。

首次结构探测与连接器修复走人工任务；稳定后再启用增量。实际 403 / 登录页 / 验证码停止来源，429 遵循 Retry-After，网络超时退避，解析必填锚点缺失停止对应版本。目标网页响应、代理 CONNECT 与本地异常分开记账。
