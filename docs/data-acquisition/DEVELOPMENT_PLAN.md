## 3. 关键验收用例

| ID | 场景 | 通过条件 |
| --- | --- | --- |
| CA-01 | 同批次提交 3 次 | source_records、实体与审核任务不重复，原回执稳定 |
| CA-02 | 同幂等键不同内容 | 返回 409，原结果不可变 |
| CA-03 | 同番号不同厂牌 / 版本 | 形成独立候选，不自动合并 |
| CA-04 | 日期冲突 / 空值 | 保留证据；明确裁决；空值不清除已确认字段 |
| CA-05 | 结构变化 / 非作品页 | 隔离版本，无乱码或整页文本进入标题 |
| CA-06 | 403 / 429 / 超时 | 按错误分类停止或退避；总预算不重置 |
| CA-07 | 断网 / Worker 崩溃 / 回执丢失 | spool 原包不丢，重传同键；无半推进游标 |
| CA-08 | 双区领取 / 过期租约 | 不双领；旧 token 无法完成或推进游标 |
| CA-09 | 人工值 / 角色 / 人物关系 | 无静默覆盖，无越权发布，缺成年确认无法公开人物 |
| CA-10 | 资料发布 / 下架 | 查询、详情、sitemap、缓存及媒体遵循现有发布/删除合同 |
| CA-11 | 手机与键盘 | 320/390/1440px 无整页溢出；搜索、弹窗、裁决可操作 |
| CA-12 | 不可信标题 / URL / 代理 | HTML 当文本显示，无脚本执行、SSRF 或凭据日志 |
| CA-13 | 采集资源竞争 | 公开 API 仍满足项目 SLO，超限停止新增任务 |
| CA-14 | 无内容变更的轮询 | 公开资料更新时间不变化，不增加“新收录” |

本轮只验证 CA-01/02/03/04 的**离线子集**、CA-11 的原型交互、CA-12 的原型转义与本机服务文件隔离；其他仍需 Go/PostgreSQL、真实网络和应用联合测试。浏览器内存 Set 的去重不替代 PostgreSQL 并发幂等验证。

## 4. 发布与回退

上线前完成来源准入、连接器版本固定、数据库合同迁移、单来源小批量、字段抽样与异人审核。先让新执行器处理 fixture，再小批量启用准入来源；公开目录仍由既有审核版本提供。正式打开 `COLLECTION_ENABLED` 前必须移除 Release A 的拒绝启动守卫并完成专项测试，不能仅改环境变量。

出现来源/解析问题暂停对应连接器，保留原包与已发布版本；出现任务事务问题暂停全局新领取。版本回退通过不可变镜像与正式资料 revision 完成，数据库优先向前修复，不能用删除候选历史掩盖问题。此次静态演示可随时停止本地预览进程，不影响现有平台。
