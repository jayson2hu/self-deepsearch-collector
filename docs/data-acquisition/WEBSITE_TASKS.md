# 新增网站与对应采集任务

状态：已在数据工作台演示中实现网站登记、任务配置与浏览器本地保存。该功能不调用正式平台 API，不写入服务器来源清单，也不向网站发起请求。

## 使用路径

1. 在“来源管理”点击“新增网站”，填写名称、网站域名、建议区域、资料字段和可选用途。
2. 点击“保存并创建任务”，新网站自动成为任务来源；也可稍后从网站卡片点击“创建采集任务”。JavDB / Jable 两个预置来源同样可以创建计划。
3. 设置任务名称、类型、目录路径、执行区域和数量上限。支持来源核验、作品增量、人物补充、详情补全及来源对账；图片与失败重跑仍需各自的执行合同，暂不作为可创建选项。
4. 保存后在任务队列看到对应网站与“待接入采集器”状态。查看配置可核对完整入口 URL、字段、区域、页数/记录限制和 JSON。
5. 待接入计划可以取消；取消状态随配置保存。已登记网站及计划刷新后保留。

真实网站任务不显示运行按钮；手动构造对样例运行函数的调用也会检查来源和执行模式。概览“运行样例任务”只挑选 fixture 任务，不能把网站计划执行成合成批次。没有网站抓取结果时，来源探测状态保持“尚未探测”。

## 输入与保存规则

| 项目 | 当前规则 |
| --- | --- |
| 网站地址 | HTTP/HTTPS 的公开域名；省略协议默认 HTTPS；统一大小写、默认端口与末尾点 |
| 不接受的地址 | 用户名/密码、IP、本机域名、自定义端口、查询参数、片段和具体目录；目录另在任务中设置 |
| 重复来源 | 同域名不能重复登记；同名网站需使用可区分名称 |
| 字段 | 番号、标题、发行日期、厂牌、人物别名；至少选择一项 |
| 任务路径 | 仅站内绝对路径；拒绝外站 URL、协议相对 URL、上级目录、查询参数及编码绕行 |
| 任务预算 | 1–20 页，1–100 条，图片 0；手动计划，不启动定时器 |
| 执行资格 | JavDB 已有本地样本解析器但网络仍关闭；Jable 与新增网站无解析器；浏览器存储中的标志不能启用连接器 |
| 本机规模 | 最多 100 个新增网站、200 个网站任务计划，配置体积不超过 1 MB |

这些是当前配置表单的输入约束，不是生产网络 SSRF 防护。正式网络执行仍需 [来源设计](./SOURCE_RESEARCH.md)与[任务架构](./ARCHITECTURE.md)中规定的来源准入、重定向/DNS/代理出口校验。

配置保存在当前浏览器的 `mujian.collection-config.v1` 条目中，包含 `version`、`sources` 与 `tasks`。读回时重新校验域名、关联、范围、预算和状态，只恢复安全的任务计划字段；不能恢复伪造的完成状态、连接器或网络开关。保存失败保留表单并显示失败原因，不显示已创建成功。配置损坏时保留原存储内容，不自动覆盖。

网站与计划本地保存；fixture 运行、合成审核与展示状态仍在内存中，刷新重置。换机器、换浏览器、清理浏览器数据、变更 SSH 转发后的访问端口都会影响可读到的本机配置，不具有账户或服务器同步能力。单个 HTML 的本地存储能力取决于浏览器；不可用时会明确报错。

右上角“导出”新增 `configuration` 对象，包含本机网站与任务计划，可用于备份和后续接口集成评审。当前没有导入界面，导出的计划也不能直接当作已授权的生产任务执行。

## 代码与后续接入

- [工作台管理交互](../../scripts/templates/collection-management.js)：表单、来源卡片、任务详情、本机存储及导出。

要让真实网站任务可执行，需要在现有 JavDB 样本解析器之外完成来源准入、受控联网执行器、正式 Go 任务接口、来源版本登记、服务端持久化、区域 Worker 调度和批次接收；Jable 与新增网站还需各自的有效样本和解析器。这个入口解决配置与计划创建，不代表这些生产能力已完成；实施顺序见[开发计划](./DEVELOPMENT_PLAN.md)。
